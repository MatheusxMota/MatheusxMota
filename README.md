### 🚀 Experiência & Projetos de Destaque

#### 💳 Sistema Web de Contas a Pagar e a Receber
*   **Stack:** TypeScript, React, Next.js (Server Actions), Tailwind CSS e Supabase.
*   **Impacto:** Desenvolvimento de aplicação para controle de registros financeiros, formulários e listagens. Substituiu um serviço terceirizado, centralizando o controle interno e aumentando a autonomia operacional da empresa.

#### 📊 Sistema de Visualização de Dados de Estoque e Obras
*   **Stack:** Python, Streamlit, Pandas e NumPy.
*   **Impacto:** Criação de dashboards interativos para análise de custos, volume de materiais e rastreabilidade de estoque. Apoiou a tomada de decisão financeira, identificando gargalos operacionais e refinando critérios de cobrança.

#### 🌐 Front-end de Site Institucional
*   **Stack:** TypeScript, React, Next.js e Tailwind CSS.
*   **Impacto:** Atuação direta no desenvolvimento da interface com foco em UX/UI, responsividade, acessibilidade e integração de canais de comunicação corporativos.
